Aplicativo de linha de comando em Python para acompanhar valores que clientes ou conhecidos ainda precisam pagar. Foi desenvolvido para uma atividade prática sobre funções em Python.

Opção
Funcionalidade
Cadastrar um valor com nome, descrição e valor em reais. 
Listar os registros com o status de cada pagamento. Marcar um registro como recebido pelo seu número na lista. 
Somar os valores que continuam pendentes. 
Encerrar o programa. |

Cadastre R$ 150,50 em nome de Ana pela criação de uma arte. Selecione a opção 4 para conferir o total. Em seguida, use a opção 3 para marcar o registro como recebido. Ao consultar o total novamente, o valor pendente será de R$ 0,00.

O menu usa while para permanecer aberto e if, elif e else para selecionar a opção. Cada ação do menu tem sua própria função e recebe a lista de registros como parâmetro. A função somar_pendencias usa return para devolver o total, e a interação com o terminal usa input() e print().
